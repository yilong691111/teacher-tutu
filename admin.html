發布前檢查

發布到 GitHub Pages

  1. 在本後台完成修改。
  2. 按「下載 site-data.js」。
  3. 到 GitHub 專案，開啟 data/site-data.js。
  4. 上傳／覆蓋剛下載的檔案，按 Commit changes。
  5. GitHub Pages 會自動顯示新版內容。

匯入現有資料

如果換電腦，先從 GitHub 下載目前的 data/site-data.js 或使用之前備份的 JSON，再從這裡匯入。

本機草稿

每次儲存都會同步寫入瀏覽器 localStorage。清除瀏覽器資料前，請先下載備份。

確定要刪除嗎？

刪除後仍可從備份檔復原。
