# 官網到訪與著色本下載統計

啟用日期：2026-11-15。官網維持 GitHub Pages，統計使用帳號中免費方案的 `teacher-tutu-statistics` 專案（`ukcgssigwretmfgquowo`，東京）。

## 顯示與計算

- 網頁最上方顯示累計到訪人數，手機也顯示。同一瀏覽器以本機隨機識別碼計一次；重新整理或開其他分頁不重複增加。不同瀏覽器、裝置或清除網站儲存空間後會視為新訪客，因此這是瀏覽器人數估計。
- 每本著色本卡片顯示下載次數，下載視窗另顯示總次數。從人物介紹進入同一份著色本的「下載」連結也會統計。
- PDF 成功取得、通過檔頭檢查並交給瀏覽器下載後才送出事件；無法知道使用者最後是否把檔案存到裝置。預覽 PDF 不計次。相同瀏覽器與書籍在 10 秒內重複下載只計一次。
- 草稿預覽、本機預覽與後台編輯不會增加數字。統計離線時顯示 `—`，下載仍可正常使用。
- 不回填啟用前的歷史數字。數字不存入 CMS 備份，發布草稿不會重設統計。

## 維護

`schema.sql` 為已套用的資料庫結構；`index.ts` 和 `handler.mjs` 為 `tutu-statistics` Edge Function 原始碼。函式保留 JWT 檢查，前台只帶公開 anon 金鑰；服務角色金鑰僅由 Supabase 環境提供。

三張資料表均開啟 RLS，撤銷 anon/authenticated 的直接讀寫；沒有面向訪客的資料表政策是刻意的拒絕存取設定。兩個 RPC 都是 security invoker 且只授權 service_role。前台只能讀取彙總或增加經驗證的事件，無法任意設定或重設次數。原始訪客識別碼在函式中雜湊後才寫入，不記錄 IP、姓名或聯絡資訊；下載去重收據保留一天。

下載事件的書籍 ID 與 PDF 路徑必須符合目前官網公開的 `data/site.json`；書籍清單快取最多 60 秒，新增著色本後自動支援統計。來源限制僅為防止其他網頁誤用，並非防機器人或獨立真人驗證。

測試：`node --test *.test.cjs product-festival.test.js`。另以資料庫回滾交易驗證重複訪客與下載去重，並驗證公開 API 的跨來源預檢。
